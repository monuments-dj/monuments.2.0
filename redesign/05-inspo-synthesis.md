## What each site is actually doing (measured)

**Monolog** — Khteka w500 as the ONLY display voice (45 to 140px, one weight) +
Suisse Mono for every label. Charcoal + off-white, b&w photography. Wordmark does a
glyph substitution (the O is a custom shape). Stories carry per-project METRICS
(522%, $100K+). Quote-led hero. Giant condensed "PROJECT JOURNEY" banner. Numbered
mono tags on everything.

**Code by Jesse** — PP Neue Montreal (grotesque) with PP Editorial New ITALIC spliced
into the same headline: key words flip to serif italic mid-sentence, plus hand-drawn
orange scribble underlines. Warm dark duotone hero. Stats as plain rows (30+, 40+,
10+). Giant cropped wordmark in the footer.

**Work by W** — custom Whisper grotesque incl. condensed, up to 300px, one weight.
Near-black, sparse. A backslash "\" prefixes every label as a punctuation brand
system ("\ ABOUT", "\ KAHF \ BRAND SETUP"). Services as numbered accordion (01/03).

**Tiny Wins** — Suisse Intl at 2-3 weights + Suisse Intl Mono captions; serifs appear
only inside client work. White-first. Statement hero split in two columns ("HOW YOU
MAKE THEM FEEL / IS THE ONLY THING THAT MATTERS") with type deliberately cropping off
the container. Proof stats as one plain text row (357% average client value growth,
7 unicorns, $10B+ raised). Video-first work. One red-dot accent.

## The shared DNA (this is the brief)

1. **One characterful grotesque, one or two weights, that's it.** Khteka / Whisper /
   Neue Montreal / Suisse. Personality comes from the FACE and one custom quirk, never
   from weight variety. (Round 1-2 failure: Inter/Archivo have no quirk; and the current
   deploy's 29 combos are the exact opposite of this discipline.)
2. **Mono is always the second voice.** Labels, tags, IDs, colophons. (Validates the
   contact-sheet element DJ locked.)
3. **A third "humanity" voice, used in drops:** serif italic spliced into headlines
   (Jesse), or a hand-made element (chalk eye, scribble underline, Lovely Mess). Never
   paragraphs.
4. **Type touches the photography.** Titles overlap, crop, and bleed into b&w/duotone
   macro imagery. Type and image are one composition, not stacked blocks.
5. **Statement-led heroes.** A conviction, not an introduction.
6. **Stats as plain text rows,** inline and quiet, not styled stat-bands.
7. **Punctuation as brand system:** backslash (W), red dot (TW), arrow (Monolog),
   spark ✳ (Monuments). One repeated glyph everywhere.
8. **Wordmark glyph substitution** (Monolog O, adj, nueu) = exactly the M✳NUMENTS move,
   independently validated by his inspo.
9. Charcoal-dark or white-first; ONE accent color used tiny.
10. **Blackletter heritage** can return in stamp-sized doses (archive stamp, est.
    monogram), never as a reading voice.

## Proposed type direction (for DJ sign-off before building)

- **Display: Bricolage Grotesque** (Google; quirky humanist grotesque with variable
  width incl. condensed, the Khteka/Whisper lane) at w600 + a condensed cut for
  banners. Alternates if too quirky: Clash Grotesk or Cabinet Grotesk (Fontshare).
- **Metadata: Fragment Mono** (the Suisse Mono lane; already proven in the locked
  contact-sheet element).
- **Humanity accent: Instrument Serif Italic** for single emphasized words inside
  headlines (the Jesse splice), plus hand-drawn annotations (grease-pencil red,
  Lovely Mess energy) reserved for marks and notes.
- Palette: charcoal ink + paper white + ONE accent (candidates: grease-pencil red
  from F, or a cobalt in the Found Objects lane). Photography b&w/duotone-forward.
- Layout grammar: statement hero with type cropping into a full-bleed image, plain
  stat row, contact-sheet element, mono tags with the ✳ or \ prefix system.
